個人開発の新作として、ユーザー登録不要でURLを共有するだけで即座にオンライン対戦が可能なボードゲームプラットフォーム「Board Verse」をリリースしました。

サイトURL: [https://board-verse.vercel.app/](https://board-verse.vercel.app/)

## Board Verse とは

「Board Verse」は、面倒なユーザー登録やログインを一切排除し、**「URLを送るだけですぐに遊べる」**ことをコンセプトにしたオンラインボードゲームプラットフォームです。

現在、以下のゲームをプレイすることができます。

- リバーシ (Reversi)
- 将棋 (Shogi)
- 五目並べ (Gomoku)
- 2048 (CPU対戦/パズル)
- 大富豪 (Daifugo)

特に「大富豪」については、革命、8切り、11バック、階段、縛りといった主要なローカルルールにも対応しており、本格的な対戦が楽しめます。

## 主な機能

- **即時対戦**: 部屋を作成して発行されたURLを友だちに送るだけで、すぐに対戦を開始できます。
- **CPU対戦**: 一人でも練習ができるよう、CPU対戦機能を搭載しています。
- **PWA対応**: iOSやAndroidのホーム画面に追加することで、アプリのような感覚でスムーズに起動できます。
- **ダークモード対応**: モダンなUIデザインで、夜間のプレイも快適です。

## 技術スタック

「Board Verse」は、最新のWeb技術を組み合わせて構築されています。

- **Frontend**: Next.js (App Router), TypeScript, Tailwind CSS
- **UI Components**: Radix UI, Lucide React
- **State Management**: SWR (データフェッチ・同期)
- **Backend/Database**: Vercel KV (Redis)
- **Runtime**: Node.js / Bun

オンライン対戦の同期には Vercel KV (Redis) を活用し、ポーリングベースでありながらもストレスの少ない対戦体験を実現しています。

## おわりに

「ちょっと時間が空いたときに、誰かと手軽にボードゲームを楽しみたい」という思いからこのサービスを作りました。
今後も新しいゲームの追加や、UI/UXの改善を継続していく予定です。

ぜひ、友だちを誘って遊んでみてください！
