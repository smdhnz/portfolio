# ポートフォリオサイトを開設しました

こんにちは、Fumiya Katoです。
この度、自身のポートフォリオサイトを新しく開設しました。

「雰囲気エンジニア」として、技術力のアピールはもちろんですが、それ以上に「なんとなくいい感じ」な世界観を表現することを目標に作りました。

## 技術スタック

このサイトは以下の技術を使って構築されています。最新のトレンドを（AIに言われるがままに）取り入れています。

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: Shadcn UI
- **Animations**: React Bits
- **Font**: Geist / Noto Sans JP / Zen Kurenaido (初期案)

特に **React Bits** のアニメーションコンポーネントを多用しており、トップページの文字演出やカードのホバーエフェクトなどで「動く楽しさ」を取り入れました。

## AIとの共創

このサイトの構築には、生成AI（Gemini）をフル活用しました。
コードの実装はもちろん、デザインの提案、文言の調整、さらにはこのブログ記事のサムネイル画像の生成まで、AIがパートナーとして並走してくれました。

「0から1を作るのは苦手」と公言している私にとって、AIは最強の相棒です。
私が「こんな感じで〜」とあいまいに伝えたことを、AIが具体的なコードやデザインに落とし込んでくれる。まさに「雰囲気エンジニア」の本領発揮といったところでしょうか。
